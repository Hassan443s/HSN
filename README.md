HSN Engine

HSN Engine is a mobile-first 2D game engine built from the ground up for Android devices. The goal of this project is to make game development possible directly from a phone, without requiring a PC.

Why HSN Engine?

Most professional game engines are designed primarily for desktop computers. While a few mobile options exist, they often have limited features, poor performance, or are difficult to use for creating larger projects.

HSN Engine was created to solve this problem by providing a powerful engine designed specifically for mobile devices.

Vision

The long-term goal of HSN Engine is to become a complete 2D game engine capable of creating almost any type of 2D game, while keeping the workflow simple and optimized for touch screens.

Whether you want to build:

- Platformer games
- RPGs
- Puzzle games
- Action games
- Endless runners
- Top-down games
- And many more...

HSN Engine aims to provide the tools needed to make it possible.

Mobile First

Unlike traditional engines that are later adapted for mobile, HSN Engine is designed for mobile from day one.

Features include:

- Full touch support
- Optimized for Android devices
- Lightweight architecture
- Mobile-friendly editor
- Designed to work without a computer

Current Status

HSN Engine is currently under active development. New systems and improvements are being added continuously.
